02 / 05 Зачем и что именно

Проблема, которую закрываем

  • Нечёткие заключения и пропущенный follow-up — источник диагностических ошибок и юридических рисков
  • Ручной аудит качества не масштабируется на тысячи репортов
  • Расхождение «описание ↔ заключение» некому ловить сплошным потоком

Гипотеза: система флагует проблемные репорты с согласием, близким к согласию между экспертами — обеспечивая сплошной контроль в режиме «человек в цикле».

03 / 05 Подход

Две дорожки под разную природу метрик

Дорожка A · жёсткие метрики (M2, M3)

Дообученный французский энкодер + правила

CamemBERT-bio / DrBERT — готовые open-source модели для французского медтекста. Хорошо определённые задачи классификации и извлечения слотов. Дёшево на инференсе.

Дорожка B · мягкие метрики (M1, M4)

LLM-as-judge со строгим рубрикатором

Open-weights LLM (Mistral / Qwen) как «оценщик». Для M4 — строгое сопоставление находок по пунктам, а не «оцени 1–5»: воспроизводимо и без произвола.

Bootstrap

LLM даёт черновую разметку → верификация людьми → дистилляция жёстких метрик в дешёвый энкодер.

Приватность

Open-weights, on-prem. Данные пациентов → де-идентификация и RGPD/GDPR до старта.

Не с нуля

Ничего не тренируем «с чистого листа» — берём готовые французские биомедицинские модели.

04 / 05 Этапы

Сначала определения и эталон — потом модели

Ключевой принцип: пока радиологи между собой не согласны, что такое «чёткое заключение», модель это не выучит. Фазы 0–2 — фундамент.
