03 / 13 Project 1 · Summary

AI vs report concordance - context sets the value of an alert

Design (canonical cohort)
  • 888 BoneView DOUBT alerts, 2025, 20-site network, mature deployment
  • LLM (Claude Opus 4.8) applies an arbitrated rule set - intended-use fit from Indications; ground truth (Anomaly / Doubt / Negative) from Conclusion
  • Confirmation rate = Anomaly / (Anomaly + Negative); reference = radiologist report

04 / 13 Project 1 · Critical review

Strong thesis - the honest ceiling is the report reference

Holds up
  • Novel, clinically important angle; monotone dose-response gradient
  • Large, real-world cohort; anatomy-adjusted regression; Wilson CIs
  • Ground truth already aligned to intended use (effusion in scope)
  • Gleamer COI disclosed and mitigated by independent extraction
Limits the claim
  • Incorporation bias: report = reference, AI on-screen in 93% of reads → reference not independent. Image truth is unavailable, so this is a permanent ceiling, not a fixable gap
  • Doubt-only cohort: no sensitivity/specificity - only confirmation-among-resolved
  • GT from free text, not yet human-validated (no κ); case-level, no localisation
✓ Resolved - dataset locked, being scaled

The MICCAI camera-ready N=888 / 50.6% is the canonical cut (earlier 925 / 48.2% figures superseded). Next: extend to >10k including AI-positive and AI-negative cases, converting a doubt-only sample into a device-output-balanced cohort.

06 / 13 Project 2 · Critical review

Right metrics, but under-powered model and no validation

Holds up
  • Fully local, deterministic (temp 0) - strong privacy posture
  • Clinically meaningful set; laterality & structure are high-value
  • Structural gate before semantic checks is sound engineering
Needs fixing
  • Single-radiologist gold (50 reports): no precision/recall reported yet, and one rater means no inter-annotator agreement - a 2nd reader is required to establish κ
  • Mistral 7B too small for laterality reasoning & nuanced ambiguity; inconsistent with P1's Opus-class model
  • Follow-up gated on ambiguity misses missing-follow-up on definite findings - decouple presence (Q2) from completeness (Q3)
  • Vague-word ambiguity over-flags cautiously-worded clear negatives - needs rubric-anchored "hedge resolved by action = not ambiguous"

The 50-report single-radiologist ambiguity + follow-up annotations are exactly the gold set to measure this pipeline - currently unused for validation.

07 / 13 Project 2 · Metric set & slicing

Ten metrics, computed in slices

Existing pilot pool
  • SRC structural compliance (target >= 99%)
  • SGE spelling / grammar
  • SEF laterality mismatch (droite/gauche)
  • AMI ambiguity (no clear conclusion)
  • MFR missing follow-up (delai/modalite/attendu)
  • ARDR AI-report discrepancy (region-level)
Next level
  • CQA clinical question addressed
  • CCS conclusion completeness (0-5, checklist section 6)
  • CPZ conclusion prioritization
  • SEF+ full discordance: within report & vs priors (section 8)
  • QCS weighted composite (0-100)
Slicing & ranking

Every metric in 5 slices: global · per radiologist · per region · per modality · per day-of-week. Radiologist ranking is internal only, modality-sliced, normalized per 100 reports of the same modality (min-N + shrinkage; day-of-week exploratory).

Rules grounded in the Groupe 3R "Checklist Comptes Rendus Radiologiques" (source of truth). ARDR is device-linked and region-level. Full spec: qc-metrics-spec.md.

08 / 13 The method, done properly

Two tracks by the nature of each dimension

Hard · Q2, Q3, B1, B2

Fine-tuned French encoder + rules

CamemBERT-bio / DrBERT - ready open-source French medical models, bootstrapped from pilot labels. Cheap, reproducible classification & slot extraction.

Soft · Q1 ambiguity

LLM-as-judge, rubric-anchored

One judge-grade LLM scores explicit signals - definite result? hedge resolved by action? - not a free-form "rate 1–5". Reproducible over gut scoring.

BoneView intended use - one shared yardstick for B1 / B2 (and P1 ground truth)

Radiographs of limbs, pelvis, thoracic & lumbar spine, rib cage · patients ≥ 2 y · fractures, dislocations, effusions, bone lesions. Out: skull, face, cervical spine, chest/abdomen soft-tissue, CT/MRI/US. Effusion is in scope.

Strategy: LLM bootstraps weak labels at scale → distil hard dimensions into a cheap encoder → human-in-the-loop confirmations grow the gold set.

09 / 13 Validation & data plan

Make the LLM labels trustworthy - and honest about the reference

Label validation (both projects)
  • Two-radiologist κ study: blinded, seeded, stratified subset (~150); target κ ≥ 0.61, goal ≥ 0.81; report confusion matrix
  • Validates the LLM's rule application (Indications→fit, Conclusion→GT / Q-metrics) against humans, and gives Project 2 its first inter-rater agreement (currently single-radiologist)
  • Feed systematic mismatches back into a versioned rule set; re-run only when rules change
Reference standard (Project 1)
  • Image truth is unavailable → the radiologist report is the reference. Frame results as report-concordance / appropriateness, not standalone diagnostic accuracy
  • Extend to >10k incl. AI-positive & AI-negative → per-output PPV / NPV against the report reference
  • Keep the incorporation-bias caveat permanent; strengthen with consecutive / unfiltered sampling
Note

Without image adjudication, population sensitivity/specificity are not claimable. Per-output predictive values on a device-output-balanced >10k cohort are the appropriate, defensible metrics.

10 / 13 Align the two projects

One model tier, one rubric, one scope

Model

Consistent judge tier

Validate Mistral 7B against the Opus-class model used in P1, or upgrade P2's judge. Same-strength model → comparable labels across projects.

Rubric

Shared definitions

One rubric-anchored ambiguity definition. Decouple follow-up presence (Q2) from completeness (Q3) - stop gating follow-up on ambiguity. Shared intended-use lexicon.

Scope

One BoneView scope

Effusion / dislocation / lesion handled identically in P1 GT and P2/B-metrics. Sync the workbook auto-classifier to the paper (effusion = anomaly).

Result: the peer-review quality signal (Q1–Q3) and the concordance signal (B1–B2) speak the same language and can be cross-tabulated per exam.

13 / 13 Required adjustments of methods

What to change before submission / deployment

  1. Freeze & scale the cohort. Lock MICCAI 888 as canonical; extend to >10k incl. AI-positive & AI-negative → device-output-balanced.P1
  2. Run the two-radiologist κ validation. Blinded, seeded, stratified; target κ ≥ 0.61 / 0.81; confusion matrix. Both projects' labels.Both
  3. Frame to the reference you have. Image truth unavailable → report-concordance, not accuracy; per-output PPV/NPV; keep incorporation-bias caveat.P1
  4. Lock one BoneView scope. Effusion = anomaly (confirmed); sync the workbook auto-classifier to the paper across both projects.Both
  5. Unify model & rubric. One judge-grade model; rubric-anchored ambiguity; decouple follow-up from ambiguity; shared lexicon.P2
  6. Power, validate & version. Validate P2 on the 50-report single-radiologist gold (precision/recall); enrich thin arms; fix provenance, seed & rule-set version.Both

Effusion scope and the dataset discrepancy are now resolved; image-based adjudication is off the table - the plan above reflects both.
