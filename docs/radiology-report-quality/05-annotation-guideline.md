# Рубрикатор разметки · RRQ-FR

Инструкция для радиологов-разметчиков. Цель — размечать репорты **воспроизводимо**:
два разметчика на одном репорте должны ставить одинаковые метки.

> Примеры даны на французском (язык данных), пояснения — на русском.
> Для франкоязычных разметчиков подготовьте производную версию инструкции на FR
> (термины уже французские; перевести нужно только пояснения).

**Общие правила:**
- Размечайте по тексту, а не по «как должно было быть» клинически.
- Оценивайте секцию **Conclusion / Impression**, для M4 — в сопоставлении с **Description / Résultats**.
- Если секции не выделены — сначала мысленно отделите заключение от описания.
- Сомневаетесь между двумя уровнями → выбирайте **худший** и отметьте в комментарии.

## M1 — Чёткость заключения (`clarté`) · шкала 0–3

**Вопрос:** насколько заключение однозначно, информативно и отвечает на клинический вопрос.

**Что смотреть (чек-признаки):**
- Есть ли явный вывод (а не только перечисление)?
- Есть ли чёткая рекомендация/тактика, если она уместна?
- Нет ли избыточного хеджирования (*possible*, *probable*, *ne peut être exclu*) **без** итогового вывода?
- Нет ли внутренних противоречий?

| Балл | Определение | Якорный пример (FR) |
|------|-------------|---------------------|
| **3** Отлично | Однозначно, отвечает на вопрос, чёткая тактика | «*Pneumopathie de la base droite. Contrôle radiographique recommandé à 4–6 semaines pour vérifier la résolution.*» |
| **2** Хорошо | В целом ясно, мелкие недочёты, вывод есть | «*Opacité basale droite d'allure infectieuse. Pas d'autre anomalie.*» (нет рекомендации, но вывод ясен) |
| **1** Слабо | Расплывчато, хеджирование без вывода, тактика неясна | «*Images pouvant correspondre à un foyer, à confronter à la clinique.*» (нет вывода, всё «возможно») |
| **0** Плохо | Неинформативно / противоречиво / пусто | «*Examen à corréler.*» или заключение, противоречащее самому себе |

**Пограничные случаи:**
- Нормальный репорт с чётким «*Radiographie thoracique normale.*» → **3** (однозначность важнее наличия рекомендации).
- «*Probable foyer, mais artefact non exclu*» без вывода → **1**.

## M2 — Наличие указания фолловапа (`suivi présent`) · да / нет

**Вопрос:** содержит ли репорт рекомендацию по дальнейшему наблюдению/дообследованию.

**Считается «да» (примеры триггеров, FR):**
- «*Contrôle radiographique à 3 mois.*»
- «*Compléter par un scanner thoracique.*»
- «*Nouveau cliché recommandé après traitement.*»
- «*Surveillance conseillée.*», «*à réévaluer.*»

**Считается «нет»:**
- Нет упоминания дальнейших действий.
- Только описание/диагноз без рекомендации.
- Общие фразы без действия: «*à corréler à la clinique*» **сама по себе** — НЕ follow-up (это не назначение исследования). Отметьте в комментарии, если сомневаетесь.

| Метка | Пример (FR) |
|-------|-------------|
| **Да** | «*Un contrôle TDM est recommandé dans 6 mois.*» |
| **Нет** | «*Foyer basal droit. Pas de recommandation.*» / заключение без упоминания наблюдения |

## M3 — Полнота указания фолловапа (`complétude du suivi`) · полный / неполный

> Размечается **только если M2 = Да.**

**Обязательные слоты** (отметьте наличие каждого):

| Слот | Что это | Пример (FR) |
|------|---------|-------------|
| `modalité` | Какое исследование | *radiographie, TDM, IRM, échographie* |
| `délai` | Срок | *dans 3 mois, à 6 semaines, à 1 an* |
| `zone/cible` | Область/находка | *thorax, base droite, le nodule* |
| `condition` | Условие (если применимо) | *si persistance des symptômes* |

**Правило:** отсутствует хотя бы один **обязательный** слот (modalité, délai, zone) ⇒ **неполный**.
`condition` — по ситуации (не всегда обязательна).

| Метка | Пример (FR) | Что не так |
|-------|-------------|-----------|
| **Полный** | «*Contrôle par radiographie thoracique dans 3 mois.*» | все слоты есть |
| **Неполный** | «*Contrôle recommandé.*» | нет modalité, нет délai, нет zone |
| **Неполный** | «*Nouveau scanner conseillé.*» | нет délai |
| **Неполный** | «*Surveillance à 6 mois.*» | нет modalité |

**Отмечайте, какие слоты отсутствуют** — это полезная обратная связь врачу.

## M4 — Несоответствие заключения описанию (`discordance`) · есть / нет (+ тип)

**Вопрос:** противоречит ли `Conclusion` содержанию `Description / Résultats`.

**Метод разметки — по пунктам:**
1. Выпишите значимые находки из **Description**.
2. Выпишите утверждения из **Conclusion**.
3. Сопоставьте. Отметьте несоответствие и его тип.

**Типы несоответствия:**

| Тип | Определение | Пример (FR) |
|-----|-------------|-------------|
| `T1 — пропуск` | Значимая находка в описании отсутствует в заключении | Description: «*épanchement pleural gauche*»; Conclusion молчит об этом |
| `T2 — необоснованное утверждение` | Заключение утверждает то, чего нет в описании | Conclusion: «*foyer droit*»; в Description про правое лёгкое — норма |
| `T3 — противоречие` | Прямое расхождение (латеральность / размер / динамика) | Description: «*nodule de 8 mm*»; Conclusion: «*nodule de 18 mm*»; или лево/право |

| Метка | Пример (FR) |
|-------|-------------|
| **Нет несоответствия** | Description и Conclusion согласованы по всем значимым пунктам |
| **Есть (T1)** | Пропуск значимой находки в заключении |
| **Есть (T3)** | «*base gauche*» в описании ↔ «*base droite*» в заключении |

**Важно:** мелкие стилистические отличия — НЕ несоответствие. Считается только
**клинически значимое** расхождение. Незначимые находки (напр. дегенеративные
изменения), опущенные в заключении, обычно НЕ T1 — используйте клиническое суждение
и отмечайте спорные случаи в комментарии.

---

## Что заполнять на каждый репорт

Смотрите форму в [`06-working-forms.md`](06-working-forms.md). Минимум:
`report_id, M1 (0–3), M2 (да/нет), M3 (полный/неполный/NA + отсутствующие слоты),
M4 (нет/T1/T2/T3), комментарий, флаг «спорный»`.

## Калибровка

Перед основной разметкой — совместная сессия на 10–15 репортах: каждый размечает
независимо, затем сверяете и обсуждаете расхождения. Рубрикатор уточняется до старта.
