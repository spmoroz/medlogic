# Рабочие формы для коллег · RRQ-FR

Готовые шаблоны для повседневной работы команды. CSV-версии лежат рядом в папке
[`forms/`](forms/) — импортируйте в Excel / Google Sheets / label-инструмент.

---

## Форма 1 — Разметка репорта (для радиологов)

Каждый разметчик заполняет **независимо**. Один репорт = одна строка.

| Поле | Тип / значения | Пояснение |
|------|----------------|-----------|
| `report_id` | текст | Анонимный ID репорта |
| `annotator_id` | текст | Кто размечает (A / B) |
| `M1_clarte` | 0 / 1 / 2 / 3 | Чёткость заключения |
| `M2_suivi` | oui / non | Есть ли указание фолловапа |
| `M3_completude` | complet / incomplet / NA | NA, если M2=non |
| `M3_slots_manquants` | modalité,délai,zone,condition | Через запятую; пусто если complet |
| `M4_discordance` | non / T1 / T2 / T3 | Тип несоответствия |
| `M4_note` | текст | Что именно расходится |
| `commentaire` | текст | Любые заметки |
| `litigieux` | oui / non | Спорный случай (на арбитраж) |

**Пример заполнения:**

| report_id | annotator_id | M1 | M2 | M3 | M3_slots | M4 | M4_note | litigieux |
|-----------|-------------|----|----|----|----------|----|---------|-----------|
| RX-00412 | A | 1 | oui | incomplet | délai,modalité | non | — | non |
| RX-00517 | A | 3 | non | NA | — | T3 | base gauche vs droite | oui |

## Форма 2 — Арбитраж / консенсус (для клинического лида)

Заполняется по репортам, где разметчики A и B разошлись.

| Поле | Тип / значения |
|------|----------------|
| `report_id` | текст |
| `M1_A` / `M1_B` / `M1_final` | 0–3 |
| `M2_A` / `M2_B` / `M2_final` | oui/non |
| `M3_A` / `M3_B` / `M3_final` | complet/incomplet/NA |
| `M4_A` / `M4_B` / `M4_final` | non/T1/T2/T3 |
| `raison_desaccord` | текст (почему разошлись) |
| `action_guideline` | нужно ли уточнить рубрикатор (oui/non + что) |

> Столбец `action_guideline` — источник улучшений рубрикатора между итерациями.

## Форма 3 — Лог ошибок модели (для ML + лида, фаза оценки)

Для анализа FP/FN при оценке системы.

| Поле | Тип / значения |
|------|----------------|
| `report_id` | текст |
| `metrique` | M1/M2/M3/M4 |
| `predit` | значение модели |
| `gold` | эталон |
| `type_erreur` | FP / FN / off-by-one (M1) |
| `cause_probable` | сегментация / хеджирование / редкая формулировка / … |
| `exemple_fragment` | цитата из репорта (де-идентиф.) |
| `idee_correction` | правило / промпт / данные |

---

## Форма 4 — Еженедельный статус (для встреч)

| Поле | Значение |
|------|----------|
| `semaine` | Неделя N |
| `phase_courante` | Ф0…Ф6 |
| `checkpoint` | CP1…CP6 (см. runbook) |
| `fait` | что сделано |
| `bloquant` | блокеры (в т.ч. правовые/данные) |
| `metriques_actuelles` | IAA / F1 / κ на текущий момент |
| `prochaines_etapes` | план на неделю |
| `risques` | новые/изменившиеся риски |

---

## Как использовать

1. Скопируйте CSV из [`forms/`](forms/) в рабочую таблицу.
2. Разметчики A и B заполняют **Форму 1** независимо (не подсматривая друг у друга).
3. ML-инженер считает IAA (κ) по совпадению полей.
4. Расхождения → **Форма 2**, арбитраж лида → консенсус-метки.
5. На оценке модели → **Форма 3**.
6. На встречах → **Форма 4**.
