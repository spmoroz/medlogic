# Методология · RRQ-FR

Технический подход к анализу качества французских радиологических репортов.
Опирается на литературу (см. [`references.md`](references.md)): специализированные
французские энкодеры (CamemBERT-bio, DrBERT), NLP-подходы к детекции follow-up и
actionable findings, и LLM-as-judge для оценки радиологических репортов.

---

## 1. Общий принцип: две дорожки под разные метрики

Метрики неоднородны по природе, поэтому под них — разные инструменты:

| Дорожка | Метрики | Инструмент | Почему |
|---------|---------|-----------|--------|
| **A. Жёсткие** | M2, M3 | Дообученный энкодер + правила | Хорошо определены, много размеченных данных, дёшево на инференсе |
| **B. Мягкие** | M1, M4 | LLM-as-judge с рубрикатором | Семантические, требуют «понимания», нет чёткого правила |

**Стратегия данных:** bootstrap через LLM. На старте нет разметки → LLM даёт
черновые метки (weak labels) и работает судьёй; затем на золотом наборе
дистиллируем «жёсткие» метрики в дешёвый энкодер.

## 2. Препроцессинг (общий для всех метрик)

1. **Де-идентификация** — до любой обработки (RGPD). Удаление ФИО, дат, ID, адресов.
2. **Сегментация секций** — разбить репорт на:
   - `Indication` (motif / renseignements cliniques)
   - `Technique`
   - `Description` / `Résultats` (findings)
   - `Conclusion` / `Impression`
   Метод: правила по заголовкам (регекспы на французские заголовки) + fallback-классификатор строк.
   **Критично:** M4 сравнивает `Description` ↔ `Conclusion`, поэтому корректная сегментация — предпосылка.
3. **Нормализация** — единицы, аббревиатуры (по необходимости), нижний регистр для правил.

## 3. Модели

### 3.1 Энкодеры (дорожка A)

- **CamemBERT-bio** (`almanach/camembert-bio-base`) — French biomedical, continual pre-training от camembert-base; +2.54 F1 в среднем на 5 biomedical NER задачах.
- **DrBERT** (`qanastek/DrBERT`) — French RoBERTa на медицинском корпусе NACHOS.
- ⚠️ **Лимит 512 токенов** у обоих. Решения: работа посекционно (для M2/M3 достаточно секции Conclusion/Description) или long-context вариант (**ModernCamemBERT-bio**).
- Выбор между CamemBERT-bio и DrBERT — эмпирически на dev; DrBenchmark даёт ориентиры, но финальное решение по вашим данным.

### 3.2 LLM (дорожка B)

- **Open-weights, on-prem** (RGPD): Mistral (сильный французский, французская модель) или Qwen — по инфраструктуре.
- Инференс: vLLM (throughput) или Ollama (простота пилота).
- **Детерминизм:** фиксировать temperature (низкую), seed; версия модели заморожена и записана в отчёт.
- **Structured output:** JSON-схема на каждый вызов (оценка + обоснование + извлечённые элементы).

## 4. Методика по каждой метрике

### M2 — Наличие указания фолловапа (бинарно)

- **Задача:** классификация репорта/секции Conclusion: есть ли рекомендация по наблюдению.
- **Baseline:** правила — «imaging term» рядом с «action term» (напр. *«contrôle»*, *«à réévaluer»*, *«suivi»*, *«nouveau cliché»* рядом с модальностью/сроком).
- **Модель:** дообученный CamemBERT-bio/DrBERT (бинарный классификатор). Гибрид правил+модели обычно > каждого по отдельности.
- **Данные:** LLM weak labels → верификация → train.

### M3 — Неполное указание фолловапа (слоты + полнота)

- **Задача:** если follow-up есть (M2=да), проверить полноту по обязательным слотам.
- **Обязательные слоты:**
  - `modalité` (какое исследование: RX / TDM / IRM / échographie…)
  - `délai` (срок: «dans 3 mois», «à 6 mois»…)
  - `zone/cible` (анатомическая область / целевая находка)
  - `condition` (при каком условии, если применимо: «si persistance des symptômes»)
- **Метод:** извлечение сущностей (NER/slot-filling на энкодере) → правило: отсутствие обязательного слота ⇒ «неполный».
  Подтверждается литературой: неполноту фиксируют по отсутствию сопутствующих элементов (анатомия, измерения, срок).
- **Выход:** метка «полный / неполный» + какие слоты отсутствуют (для полезной обратной связи врачу).

### M4 — Несоответствие заключения описанию (согласованность)

- **Задача (самая сложная):** противоречит ли `Conclusion` тому, что в `Description`.
- **Метод — строгое информационное сопоставление** (не «оцени 1–5»):
  1. LLM извлекает структурированный список находок из `Description`.
  2. LLM извлекает список утверждений из `Conclusion`.
  3. Попарное сопоставление: каждое утверждение заключения → подтверждено / противоречит / отсутствует в описании; каждая значимая находка описания → отражена ли в заключении.
  4. Типизация расхождения: пропуск значимой находки в заключении; утверждение в заключении без основания в описании; противоречие (латеральность, размер, динамика).
- Такой binary-matching-подход надёжнее открытого рассуждения (снижает произвол судьи).
- **Порог тревоги:** настраивается на recall (лучше лишний флаг, чем пропуск).

### M1 — Чёткость заключения (порядковая 0–3)

- **Задача:** оценить однозначность и информативность заключения.
- **Метод:** LLM-as-judge по рубрикатору с якорными примерами (см. guideline). Шкала 0–3:
  - 3 — однозначное, отвечает на клинический вопрос, чёткая рекомендация;
  - 2 — в целом ясно, мелкие недочёты;
  - 1 — расплывчато, избыток хеджирования без вывода;
  - 0 — неинформативно / противоречиво.
- **Снижение произвола:** рубрика требует от судьи отмечать конкретные признаки (наличие вывода, наличие рекомендации, избыток «possible/probable» без заключения), а не выставлять «общее впечатление».
- **Валидация:** κ и MAE против консенсус-меток радиологов.

## 5. Оценка

### Метрики по задачам

| Метрика | Основные показатели |
|---------|--------------------|
| M2 (бинарно) | Precision, Recall, F1, AUC |
| M3 (полнота) | F1 по метке «неполный»; точность извлечения слотов (по слоту) |
| M4 (несоответствие) | Recall (приоритет), Precision, FP-rate; отдельно по типам расхождений |
| M1 (порядковая) | Quadratic-weighted κ (модель↔эксперт), MAE, точность ±1 |

### Принципы честной оценки

- **Замороженный test-сплит**, не участвующий в разработке промптов/обучении.
- Все числа — против **консенсус-меток** (после арбитража), а не одного разметчика.
- Потолок модели ограничен согласием людей: если κ_человек-человек = 0.65,
  ждать κ_модель > 0.65 наивно. **IAA — верхняя планка.**
- Отчёт включает анализ ошибок (типология FP/FN) и калибровку LLM-судьи.

## 6. Валидация и калибровка LLM-судьи

- **Воспроизводимость:** один и тот же вход → один выход (fixed seed/temp).
- **Устойчивость:** перефразировки не должны менять оценку (тест на парафразах).
- **Смещение:** проверить склонность к завышению; при необходимости — калибровка порогов/рубрики.
- **Ablation:** сравнить «строгое сопоставление» vs «прямая оценка» для M4/M1.

## 7. Human-in-the-loop и дообучение

- MVP работает в режиме **ассистента**: флагует, радиолог решает.
- Подтверждения/опровержения радиологов → расширение золотого набора.
- Активное обучение: в первую очередь размечать репорты, где модель не уверена.
- Плановое дообучение энкодеров по мере накопления меток.

## 8. Почему именно так (резюме обоснования)

- **Не тренируем с нуля** — есть готовые французские биомедицинские энкодеры.
- **Open-weights + on-prem** — данные пациентов, RGPD.
- **LLM сначала** — быстрый прототип по всем метрикам без разметки; затем дистилляция «жёстких» метрик в дешёвый энкодер.
- **Строгое сопоставление вместо «оцени N»** — воспроизводимость и меньше произвола судьи.
- **Узкий скоуп (RX thorax)** — меньше словарь → выше точность на малых данных.
